Sobre

Sou o Ícaro, estudante de Análise e Desenvolvimento de Sistemas em Embu das Artes (SP), no 4º semestre. Meu foco é back-end com Java e Spring Boot, construindo APIs REST em camadas, com tratamento global de exceções, autenticação JWT/Spring Security e testes guiados por TDD (RED → GREEN → REFACTOR).

Também trabalho com Python/FastAPI para serviços leves e estou ampliando o stack para TypeScript, Node.js, NestJS e React como parte de um projeto acadêmico com Stripe e componentes de IA/ChatBot para a ExpoTech.

Fora do código, sou entusiasta de Linux — migrei recentemente de CachyOS para Arch Linux puro, faço ricing com Hyprland/KDE e mantenho um pequeno stack self-hosted em Docker (Nextcloud, Jellyfin).
